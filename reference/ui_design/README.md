# 중세난장판 UI 디자인 참고 (마을 게시판 스타일)

Claude 디자인 캔버스에서 만든 시안의 원본 HTML. 1920x1080 기준 좌표.
같은 이름의 .jpg가 완성된 모습 (먼저 이걸 볼 것). .html은 정확한 좌표·크기·색을 읽는 용도 — {{...}} 자리는 맨 아래 스크립트(renderVals)가 채우는 값.
Godot로 옮길 때는 **좌표·크기·색·문구의 기준**으로만 쓴다 (img/의 캐릭터 그림은 게임 DerpModel을 찍은 것 — 게임에선 실제 3D 모델을 쓴다).

| 파일 | 화면 |
|---|---|
| Guide.html | UI 키트와 규칙 (재질 3개, 색, 글꼴, 버튼 3종, 경기 화면 규칙, 말투) ← 먼저 읽기 |
| Main.html | 메인 메뉴 (나무 이정표 메뉴, 매달린 제목 간판) |
| ClassSelect.html | 병과 선택 ("누가 나갈래?", 합격 도장, "이놈으로 출전") |
| Hud.html | 경기 화면 HUD (쟁탈전) |
| Result*.html | 결과 화면 4종 (개인전 1~3등 / 4등 이하 / 쟁탈전 승리 / 패배) |

개구 글꼴: fonts/Gaegu-Bold-sub.woff2 (Gaegu Bold, SIL OFL 1.1 — fonts/OFL-Gaegu.txt). 완성형 한글 2350자 + 영문·숫자·기본 문장부호만 남긴 것. '…'는 없으니 '...'로 쓰거나 Noto 대체 폰트를 fallback으로.
